# CodeToAGI - Episode 3 Challenge
## Create Your Own Variables | Variables & Data Types

### 🎯 Challenge Description
Create 4 variables about yourself and print them:
- `your_name` - as a string (text)
- `your_age` - as an integer (whole number)
- `your_city` - as a string (text)
- `learning_python` - as a boolean (True or False)

### 📝 Code
```python
# Create 4 variables
your_name = "Mahaz Abbasi"
your_age = 32
your_city = "Islamabad"
learning_python = True

# Print all variables
print("--- My Profile ---")
print(your_name)
print(your_age)
print(your_city)
print(learning_python)
